# Contributing

VENT is a deliberately focused product. Changes should strengthen the core flow rather than broaden the product.

1. Create a short-lived branch.
2. Keep commits atomic and use imperative Conventional Commit messages.
3. Run `pnpm lint` and `pnpm build` before opening a pull request.
4. Explain user-visible behavior changes and privacy implications.
5. Do not commit secrets, transcripts, generated recordings, or personal journal data.

Features that turn VENT into therapy, medical advice, a generic assistant, a task manager, or a social network are out of scope.
